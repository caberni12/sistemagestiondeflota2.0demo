# Actualización 3.18.7

1. Reemplace el contenido del proyecto Apps Script por los archivos de esta versión, especialmente `Codigo_Completo.gs`.
2. Ejecute una vez la función `configurarRecursosOficiales()` desde el editor de Apps Script y autorice el acceso solicitado.
3. Ejecute `instalarSistema()` para asegurar las hojas y catálogos faltantes.
4. Publique una nueva versión de la aplicación web.

La función de configuración corrige automáticamente cualquier ID de hoja antiguo guardado en las propiedades del proyecto.
